# عزنا بطبعنا — اليوم الوطني السعودي 96 🇸🇦💎

نسخة البداية لموقع Flutter Web، Mobile First.

## الأقسام
- فصفص صورتك
- صمّم تهنئتك
- تميّز بخلفية شاشة

## التشغيل
```bash
flutter pub get
flutter run -d chrome
```

## Build
```bash
flutter build web --release
```

## Vercel
المشروع مجهز بملف `vercel.json` لتوجيه مسارات Flutter Web إلى `index.html`.
